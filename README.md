# Yingzhe Zhu Academic Website

This repository contains a Hugo-powered academic website for Yingzhe Zhu, a PhD candidate in Sociology at Northwestern University.

The site is designed for GitHub Pages. Content lives in Markdown and YAML files so it can be edited directly on GitHub.

## Local Preview

```sh
hugo server --disableFastRender
```

Then open the local URL Hugo prints.

## Build

```sh
hugo --gc --minify
```

## Editing

See `UPDATING.md` for plain-language instructions for updating the bio, research, awards, CV, photo, and news items.
